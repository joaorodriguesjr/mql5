Y\_Size

Sets the value of "Y\_Size" property.

```
bool  Y_Size(
   int  size      // property value
   )
```

Parameters

size

[in]  New vertical size property value.

Return Value

true - successful, false - cannot change the property.

Note

To get the values of "X\_Size" and "Y\_Size" properties, use the [X\_Size](cchartobjectlabelx_size.md) and [Y\_Size](cchartobjectlabely_size.md) methods of the parent [CChartObjectLabel](cchartobjectlabel.md) class.
