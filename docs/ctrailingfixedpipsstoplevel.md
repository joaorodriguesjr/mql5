StopLevel

Sets the value of Stop Loss level.

```
void  StopLevel(
   int  stop_level      // level
   )
```

Parameters

stop\_loss

[in]  The value of Stop Loss level (in conventional 2/4-digit points).

Note

If Stop Loss level is equal to 0, the Trailing Stop is not used.
