ShowValue

Sets the visibility flag for the values (FLAG\_SHOW\_VALUE).                                   

```
 void  ShowValue(
   const bool  flag,  // flag value 
   )
```

Parameters

flag

[in] Flag value:

* true the value becomes visible.
* false the value becomes invisible.
