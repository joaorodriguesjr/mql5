AddItem

Adds an item to the control.

```
bool  AddItem(
   const string  item,     // text
   const long    value=0   // value
   )
```

Parameters

item

[in]  Added control label text.

value=0

[in]  Value associated with the added control.

Return Value

true - successful, otherwise - false.
