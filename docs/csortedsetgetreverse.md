GetReverse

Gets a copy of the current sorted set, in which all the elements are arranged in a reverse order.

```
bool GetReverse(
   T&  array[]     // an array for writing
   );
```

Parameters

&array[]

[out] An array for writing.

Return Value

Returns true on successful, or false otherwise.
