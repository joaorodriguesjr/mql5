ShowScaleLeft

Sets the visibility flag value for the left scale (FLAG\_SHOW\_SCALE\_LEFT).                            

```
 void  ShowScaleLeft(
   const bool  flag,  // flag value 
   )
```

Parameters

flag

[in] Flag value:

* true the left scale becomes visible.
* false the left scale becomes invisible.
