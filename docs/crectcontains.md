Contains

Checks if the point is inside the CRect class area.

```
bool  Contains(
   const int  x,     // X coordinate
   const int  y      // Y coordinate
   )
```

Parameters

x

[in]  X coordinate.

y

[in]  Y coordinate.

Return Value

true - the point is inside the area (including borders), otherwise - false.
