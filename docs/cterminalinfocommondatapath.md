CommonDataPath

Gets the common data folder of all client terminals installed on the computer.

```
string  CommonDataPath() const
```

Return Value

Common data folder of all installed terminals.

Note

The common data folder of all installed terminals is defined by [TerminalInfoString()](terminalinfostring.md) function ([COMMON\_DATA\_PATH](terminalstatus.md#enum_terminal_info_integer) property).
