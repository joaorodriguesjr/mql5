CPUCores

Gets the information about the number of CPU cores in the system.

```
int  CPUCores() const
```

Return Value

Number of CPU cores in the system.

Note

The number of CPU cores is defined by [TerminalInfoInteger()](terminalinfointeger.md) function ([TERMINAL\_CPU\_CORES](terminalstatus.md#enum_terminal_info_integer) property).
