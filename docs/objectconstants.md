Object Constants

There are 44 graphical objects that can be created and displayed in the price chart. All constants for working with objects are divided into 9 groups:

* [Object types](enum_object.md) Identifiers of graphical objects;
* [Object properties](enum_object_property.md) setting and getting properties of graphical objects;
* [Methods of object binding](enum_anchorpoint.md) constants of object positioning in the chart;
* [Binding corner](enum_basecorner.md) setting the corner relative to which an object is positioned on chart;
* [Visibility of objects](visible.md) setting timeframes in which an object is visible;
* [Levels of Elliott Waves](enum_elliot_wave_degree.md) gradation of waves;
* [Gann objects](enum_gann_direction.md) trend constants for Gann fan and Gann grid;
* [Web colors](webcolors.md) constants of predefined web colors;
* [Wingdings](wingdings.md) codes of characters of the Wingdings font.
