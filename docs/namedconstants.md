Named Constants

All constants used in MQL5 can be divided into the following groups:

* [Predefined macro substitutions](compilemacros.md) values are substituted during compilation;
* [Mathematical constants](mathsconstants.md) values of some mathematical expressions;
* [Numerical type constants](typeconstants.md)  some of the simple type restrictions;
* [Uninitialization reason codes](uninit.md) description of uninitialization reasons;
* [Checking Object Pointer](enum_pointer_type.md) enumeration of types of pointers returned by the [CheckPointer()](checkpointer.md) function;
* [Other constants](otherconstants.md) all other constants.
