SignalUnsubscribe

Cancels subscription.

```
bool  SignalUnsubscribe();
```

Return Value

Returns true if subscription has been canceled successfully, otherwise returns false. To read more about the [error](errorcodes.md) call [GetLastError()](getlasterror.md).
