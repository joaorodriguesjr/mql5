Save

Saves object parameters to file.

```
virtual bool  Save(
   int  file_handle      // file handle
   )
```

Parameters

file\_handle

[in]  handle of the binary file already opened by the [FileOpen](fileopen.md) function.

Return Value

true - success, false - error.
