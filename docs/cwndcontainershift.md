Shift

Performs the relative shift of the coordinates for all controls of the container.

```
virtual bool  Shift(
   const int  dx,     // delta X
   const int  dy      // delta Y
   )
```

Parameters

dx

[in]  Delta X.

dy

[in]  Delta Y.

Return Value

true - successful, otherwise - false.
