TryGetMax

Gets the maximum element from the sorted set.

```
bool TryGetMax(
   T&  max     // a variable for writing the value
   );
```

Parameters

&max

[out]  The variable to which the maximum value will be written.

Return Value

Returns true on successful, or false otherwise.
