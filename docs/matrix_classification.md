Matrix Classification

The section describes a set of functions for analyzing the structural properties of matrices. These methods allow us to determine whether a matrix is symmetric, Hermitian, diagonal, triangular, trapezoidal, Hessenberg, bidiagonal, or scalar. Such a classification simplifies the selection of efficient algorithms for linear algebra and optimization of computations.

| Function | Action |
| --- | --- |
| [IsSymmetric](matrix_issymmetric.md) | Check if a square matrix is symmetric |
| [IsHermitian](matrix_ishermitian.md) | Check if a square complex matrix is Hermitian |
| [IsUpperTriangular](matrix_isuppertriangular.md) | Check if a square matrix is upper triangular |
| [IsLowerTriangular](matrix_islowertriangular.md) | Check if a square matrix is lower triangular |
| [IsTrapezoidal](matrix_istrapeziodal.md) | Check if a rectangular (not square) m-by-n matrix is upper or lower trapezoidal |
| [IsUpperHessenberg](matrix_isupperhessenberg.md) | Check if a square matrix is upper Hessenberg matrix |
| [IsLowerHessenberg](matrix_islowerhessenberg.md) | Check if a square matrix is lower Hessenberg matrix |
| [IsTridiagonal](matrix_istridiagonal.md) | Check if a square matrix is tridiagonal |
| [IsUpperBidiagonal](matrix_isupperbidiagonal.md) | Check if a square matrix is upper bidiagonal |
| [IsLowerBidiagonal](matrix_islowerbidiagonal.md) | Check if a square matrix is lower bidiagonal |
| [IsDiagonal](matrix_isdiagonal.md) | Check if a square matrix is diagonal |
| [IsScalar](matrix_isscalar.md) | Check if a square matrix is scalar matrix |
