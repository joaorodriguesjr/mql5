Event Functions

This group contains functions for working with custom events and timer events. Besides this group, there are special functions for handling [predefined events](events.md).

| Function | Action |
| --- | --- |
| [EventSetMillisecondTimer](eventsetmillisecondtimer.md) | Launches event generator of the high-resolution timer with a period less than 1 second for the current chart |
| [EventSetTimer](eventsettimer.md) | Starts the timer event generator with the specified periodicity for the current chart |
| [EventKillTimer](eventkilltimer.md) | Stops the generation of events by the timer in the current chart |
| [EventChartCustom](eventchartcustom.md) | Generates a custom event for the specified chart |
