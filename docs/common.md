Common Functions

General-purpose functions not included into any specialized group are listed here.

| Function | Action |
| --- | --- |
| [Alert](alert.md) | Displays a message in a separate window |
| [CheckPointer](checkpointer.md) | Returns the type of the object pointer |
| [Comment](comment.md) | Outputs a comment in the left top corner of the chart |
| [CryptEncode](cryptencode.md) | Transforms the data from array with the specified method |
| [CryptDecode](cryptdecode.md) | Performs the inverse transformation of the data from array |
| [DebugBreak](debugbreak.md) | Program breakpoint in debugging |
| [ExpertRemove](expertremove.md) | Stops Expert Advisor and unloads it from the chart |
| [GetPointer](getpointer.md) | Returns the object [pointer](object_pointers.md) |
| [GetTickCount](gettickcount.md) | Returns the number of milliseconds that have elapsed since the system was started |
| [GetTickCount64](gettickcount64.md) | Returns the number of milliseconds that have elapsed since the system was started |
| [GetMicrosecondCount](getmicrosecondcount.md) | Returns the number of microseconds that have elapsed since the start of MQL5 program |
| [MessageBox](messagebox.md) | Creates, displays a message box and manages it |
| [PeriodSeconds](periodseconds.md) | Returns the number of seconds in the period |
| [PlaySound](playsound.md) | Plays a sound file |
| [Print](print.md) | Displays a message in the log |
| [PrintFormat](printformat.md) | Formats and prints the sets of symbols and values in a log file in accordance with a preset format |
| [ResetLastError](resetlasterror.md) | Sets the value of a predetermined variable [\_LastError](_lasterror.md) to zero |
| [ResourceCreate](resourcecreate.md) | Creates an image resource based on a data set |
| [ResourceFree](resourcefree.md) | Deletes [dynamically created resource](resourcecreate.md#dynamic_resourcecreate) (freeing the memory allocated for it) |
| [ResourceReadImage](resourcereadimage.md) | Reads data from the graphical resource [created by ResourceCreate() function](resourcecreate.md#dynamic_resourcecreate) or [saved in EX5 file during compilation](resources.md#resource_include) |
| [ResourceSave](resourcesave.md) | Saves a resource into the specified file |
| [SetUserError](setusererror.md) | Sets the predefined variable \_LastError into the value equal to ERR\_USER\_ERROR\_FIRST + user\_error |
| [SetReturnError](setreturnerror.md) | Sets the code that returns the terminal process when completing the operation. |
| [Sleep](sleep.md) | Suspends execution of the current Expert Advisor or script within a specified interval |
| [TerminalClose](terminalclose.md) | Commands the terminal to complete operation |
| [TesterHideIndicators](testerhideindicators.md) | Sets the mode of displaying/hiding indicators used in an EA |
| [TesterStatistics](testerstatistics.md) | It returns the value of a specified statistic calculated based on testing results |
| [TesterStop](testerstop.md) | Gives program operation completion command when [testing](https://www.metatrader5.com/en/terminal/help/algotrading/testing) |
| [TesterDeposit](testerdeposit.md) | Emulates depositing funds during a test. It can be used in some money management systems |
| [TesterWithdrawal](testerwithdrawal.md) | Emulates the operation of money withdrawal in the process of testing |
| [TranslateKey](translatekey.md) | Returns a Unicode character by a virtual key code |
| [ZeroMemory](zeromemory.md) | Resets a variable passed to it by reference. The variable can be of any type, except for classes and structures that have constructors. |
