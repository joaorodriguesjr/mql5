LineStyleSet

Sets the line style.

```
void  LineStyleSet(
   const uint  style      // style
   );
```

Parameters

style

[in]  Line style.

Note

The input parameter can have any of ENUM\_LINE\_STYLE enumeration values. Besides, it is possible to create a custom line drawing style.
