ReadObject

Reads data of the CObject class inheritor instance from file.

```
bool  ReadObject(
   CObject*  object      // pointer
   )
```

Parameters

object

[in]  Pointer to the CObject class inheritor instance to read.

Return Value

true - successful, false - cannot read the data.
