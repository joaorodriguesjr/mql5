CompareMagic

Compares the Expert Advisor ID (magic) with the specified value.

```
virtual bool  CompareMagic(
   ulong  magic    // identifier
   )
```

Parameters

magic

[in]  Identifier value to compare.

Return Value

true - identifier matches the specified one, otherwise - false.
