Matrix and vector products

Matrix and vector product calculations include:

* matrix multiplication
* vector multiplication
* computing covariance matrix
* computing the cross-correlation of two vectors
* computing the convolution of two vectors
* computing the correlation coefficient

| Function | Action |
| --- | --- |
| [MatMul](matrix_matmul.md) | Matrix product of two matrices |
| [GeMM](matrix_gemm.md) | General matrix multiplication (GeMM) |
| [Power](matrix_power.md) | Raise a square matrix to the integer power |
| [Dot](matrix_dot.md) | Dot product of two vectors |
| [Kron](matrix_kron.md) | Return Kronecker product of two matrices, matrix and vector, vector and matrix or two vectors |
| [Inner](matrix_inner.md) | Inner product of two matrices |
| [Outer](matrix_outer.md) | Compute the outer product of two matrices or two vectors |
| [CorrCoef](matrix_corrcoef.md) | Compute the Pearson correlation coefficient (linear correlation coefficient) |
| [Cov](matrix_cov.md) | Compute the covariance matrix |
| [Correlate](matrix_correlate.md) | Compute the cross-correlation of two vectors |
| [Convolve](matrix_convolve.md) | Return the discrete, linear convolution of two vectors |
