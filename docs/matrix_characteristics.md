Feature methods

These methods enable the receiving of matrix features, such as:

* number of rows
* number of columns
* norm
* condition number
* determinant
* matrix rank
* trace
* spectrum

| Function | Action |
| --- | --- |
| [Rows](matrix_rows.md) | Return the number of rows in a matrix |
| [Cols](matrix_cols.md) | Return the number of columns in a matrix |
| [Size](matrix_size.md) | Return the size of vector |
| [Norm](matrix_norm.md) | Return matrix or vector norm |
| [Cond](matrix_cond.md) | Compute the condition number of a matrix |
| [Det](matrix_det.md) | Compute the determinant of a square invertible matrix |
| [SLogDet](matrix_slogdet.md) | Compute the sign and logarithm of the determinant of an matrix |
| [Rank](matrix_rank.md) | Return matrix rank using the Gaussian method |
| [Trace](matrix_trace.md) | Return the sum along diagonals of the matrix |
| [Spectrum](matrix_spectrum.md) | Compute spectrum of a matrix as the set of its eigenvalues from the product AT*A |
