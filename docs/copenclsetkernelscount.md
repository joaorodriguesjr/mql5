SetKernelsCount

Sets the number of kernel objects.

```
bool  SetKernelsCount(
   const int  total_kernels      // number of kernels
   );
```

Parameters

total\_kernels

[in]  The total number of kernels.

Return Value

In case of successful execution, returns true, otherwise - false.
