ProfitLevel

Sets the value of Take Profit level.

```
void  ProfitLevel(
   int  profit_level      // level
   )
```

Parameters

profit\_level

[in]  The value of Take Profit level (in conventional 2/4-digit points).

Note

If profit level is equal to 0, the Trailing Stop is not used.
