Fill

Fills an area.

```
void  Fill(
   int         x,       // X coordinate
   int         y,       // Y coordinate
   const uint  clr      // color
   );
```

Parameters

x

[in]  X coordinate of filling starting point.

y

[in]  Y coordinate of filling starting point.

clr

[in]  Color in ARGB format.
