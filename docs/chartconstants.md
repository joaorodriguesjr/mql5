Chart Constants

Constants describing various properties of charts are divided into the following groups:

* [Types of events](enum_chartevents.md) events that occur when working with charts;
* [Chart timeframes](enum_timeframes.md) standard built-in periods;
* [Properties of chart](enum_chart_property.md) identifiers that are used as parameters of [chart functions](chart_operations.md);
* [Positioning constants](enum_chart_position.md) - value of a parameter of the [ChartNavigate()](chartnavigate.md) function;
* [Displaying charts](chart_view.md) - setting the chart appearance.
