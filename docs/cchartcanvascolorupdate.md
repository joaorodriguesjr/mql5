ColorUpdate

Updates the series colors (at the specified position).

```
 bool  ColorUpdate(
   const uint  pos,  // index
   const uint  clr,  // color
   )
```

Parameters

pos

[in] Index of the series the serial number of its addition, starting with 0. 

clr

[in] Color value.

Return Value

true if successful, otherwise false.
