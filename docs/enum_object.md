Object Types

When a graphical object is created using the [ObjectCreate()](objectcreate.md) function, it's necessary to specify the type of object being created, which can be one of the values of the ENUM\_OBJECT enumeration. Further specifications of object [properties](enum_object_property.md) are possible using functions for working with [graphical objects](objects.md).
