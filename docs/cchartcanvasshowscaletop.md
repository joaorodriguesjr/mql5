ShowScaleTop

Sets the visibility flag value for the top scale (FLAG\_SHOW\_SCALE\_TOP).                          

```
 void  ShowScaleTop(
   const bool  flag,  // flag value 
   )
```

Parameters

flag

[in] Flag value:

* true  the top scale becomes visible.
* false the top scale becomes invisible.
