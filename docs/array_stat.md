Statistical Characteristics

This group of functions calculates the Statistical Characteristics of the array elements:

* mean,
* variance,
* skewness,
* kurtosis,
* median,
* root-mean-square and
* standard deviation.

| Function | Description |
| --- | --- |
| [MathMean](mathmean.md) | Calculates the mean (first moment) of array elements |
| [MathVariance](mathvariance.md) | Calculates the variance (second moment) of array elements |
| [MathSkewness](mathskewness.md) | Calculates the skewness (third moment) of array elements |
| [MathKurtosis](mathkurtosis.md) | Calculates the kurtosis (fourth moment) of array elements |
| [MathMoments](mathmoments.md) | Calculates the first 4 moments (mean, variance, skewness, kurtosis) of array elements |
| [MathMedian](mathmedian.md) | Calculates the median value of array elements |
| [MathStandardDeviation](mathstandarddeviation.md) | Calculates the standard deviation of array elements |
| [MathAverageDeviation](mathaveragedeviation.md) | Calculates the average absolute deviation of array elements |
