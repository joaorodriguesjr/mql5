OnMouseDown

The virtual handler of the "MouseDown" (mouse click) event.

```
virtual bool  OnMouseDown()
```

Return Value

true - event processed, otherwise - false.

Note

The "MouseDown" event occurs when left mouse button is pressed on the control.
