Statistical methods

Methods for computing descriptive statistics of matrices and vectors.

| Function | Action |
| --- | --- |
| [ArgMax](matrix_argmax.md) | Return the index of the maximum value |
| [ArgMin](matrix_argmin.md) | Return the index of the minimum value |
| [Max](matrix_max.md) | Return the maximum value in a matrix/vector |
| [Min](matrix_min.md) | Return the minimum value in a matrix/vector |
| [Ptp](matrix_ptp.md) | Return the range of values of a matrix/vector or of the given matrix axis |
| [Sum](matrix_sum.md) | Return the sum of the matrix/vector elements which can also be performed for the given axis (axes) |
| [Prod](matrix_prod.md) | Return the product of the matrix/vector elements which can also be performed for the given axis |
| [CumSum](matrix_cumsum.md) | Return the cumulative sum of matrix/vector elements, including those along the given axis |
| [CumProd](matrix_cumprod.md) | Return the cumulative product of matrix/vector elements, including those along the given axis |
| [Percentile](matrix_percentile.md) | Return the specified percentile of values of matrix/vector elements or elements along the specified axis |
| [Quantile](matrix_quantile.md) | Return the specified quantile of values of matrix/vector elements or elements along the specified axis |
| [Median](matrix_median.md) | Compute the median of the matrix/vector elements |
| [Mean](matrix_mean.md) | Compute the arithmetic mean of element values |
| [Average](matrix_average.md) | Compute the weighted mean of matrix/vector values |
| [Std](matrix_std.md) | Return the standard deviation of values of matrix/vector elements or of elements along the given axis |
| [Var](matrix_var.md) | Compute the variance of values of matrix/vector elements |
| [LinearRegression](matrix_linearregression.md) | Calculate a vector/matrix with calculated linear regression values |
