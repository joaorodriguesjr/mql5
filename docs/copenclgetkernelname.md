GetKernelName

Returns name of the kernel object at the specified index.

```
string  GetKernelName(
   const int  kernel_index      // index of the kernel
   );
```

Parameters

kernel\_index

[in]  Index of the kernel object.

Return Value

Name of the kernel object.
