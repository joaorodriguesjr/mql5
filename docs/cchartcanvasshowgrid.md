ShowGrid

Sets the visibility flag value for the grid (FLAG\_SHOW\_GRID).                      

```
 void  ShowGrid(
   const bool  flag,  // flag value 
   )
```

Parameters

flag

[in] Flag value:

* true the grid becomes visible.
* false the grid becomes invisible.
