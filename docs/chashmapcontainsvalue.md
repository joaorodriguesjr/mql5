ContainsValue

Determines whether the hash table contains the key/value pair with the specified value.

```
bool ContainsValue(
   TValue  value     // value
   );
```

Parameters

value

[in]  Value.

Return Value

Returns true if the hash table contains a key/value pair with the specified value, or false otherwise.
