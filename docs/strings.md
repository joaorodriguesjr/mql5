String Functions

This is a group of functions intended for working with data of the [string](stringconst.md) type.

| Function | Action |
| --- | --- |
| [StringAdd](stringadd.md) | Adds a string to the end of another string |
| [StringBufferLen](stringbufferlen.md) | Returns the size of buffer allocated for the string |
| [StringCompare](stringcompare.md) | Compares two strings and returns 1 if the first string is greater than the second; 0 - if the strings are equal; -1 (minus 1) - if the first string is less than the second one |
| [StringConcatenate](stringconcatenate.md) | Forms a string of parameters passed |
| [StringFill](stringfill.md) | Fills out a specified string by selected symbols |
| [StringFind](stringfind.md) | Search for a substring in a string |
| [StringGetCharacter](stringgetcharacter.md) | Returns the value of a number located in the specified string position |
| [StringInit](stringinit.md) | Initializes string by specified symbols and provides the specified string length |
| [StringLen](stringlen.md) | Returns the number of symbols in a string |
| [StringSetLength](stringsetlength.md) | Sets a specified length (in characters) for a string |
| [StringReplace](stringreplace.md) | Replaces all the found substrings of a string by a set sequence of symbols |
| [StringReserve](stringreserve.md) | Reserves the buffer of a specified size for a string in memory. |
| [StringSetCharacter](stringsetcharacter.md) | Returns a copy of a string with a changed value of a symbol in a specified position |
| [StringSplit](stringsplit.md) | Gets substrings by a specified separator from the specified string, returns the number of substrings obtained |
| [StringSubstr](stringsubstr.md) | Extracts a substring from a text string starting from a specified position |
| [StringToLower](stringtolower.md) | Transforms all symbols of a selected string to lowercase |
| [StringToUpper](stringtoupper.md) | Transforms all symbols of a selected string into capitals |
| [StringTrimLeft](stringtrimleft.md) | Cuts line feed characters, spaces and tabs in the left part of the string |
| [StringTrimRight](stringtrimright.md) | Cuts line feed characters, spaces and tabs in the right part of the string |
