KernelFree

Removes an OpenCL start function at the specified index.

```
bool  KernelFree(
   const int  kernel_index      // index of the kernel
   );
```

Parameters

kernel\_index

[in]  Index of the kernel object.

Return Value

In case of successful execution, returns true, otherwise - false.
