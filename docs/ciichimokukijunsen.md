KijunSen

Returns the buffer element of the KijunSen line by the specified index.

```
double  KijunSen(
   int  index      // index
   )
```

Parameters

index

[in]  KijunSen line buffer element index.

Return Value

The buffer element of the KijunSen line of the specified index, or [EMPTY\_VALUE](otherconstants.md) if there is no correct data.
