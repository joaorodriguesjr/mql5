ShowScaleRight

Sets the visibility flag value for the right scale (FLAG\_SHOW\_SCALE\_RIGHT).                          

```
 void  ShowScaleRight(
   const bool  flag,  // flag value 
   )
```

Parameters

flag

[in] Flag value:

* true  the right scale becomes visible.
* false the right scale becomes invisible.
