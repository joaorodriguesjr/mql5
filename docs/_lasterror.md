int \_LastError

The \_LastError variable contains code of the last [error](errorcodes.md), that occurred during the mql5-program run. Its value can be reset to zero by [ResetLastError()](resetlasterror.md).

To obtain the code of the last error,  you may also use the [GetLastError()](getlasterror.md) function.
