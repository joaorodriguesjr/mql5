ContainsKey

Determines whether the sorted hash table contains the key/value table with the specified key.

```
bool ContainsKey(
   TKey  key     // key
   );
```

Parameters

key

[in]  Key.

Return Value

Returns true, if the sorted hash table contains the key/value pair with the specified key, or false otherwise.
