Codes of Errors and Warnings

This section contains the following descriptions:

* [Return codes of the trade server](enum_trade_return_codes.md) analyzing results of the [trade request](mqltraderequest.md) sent by function [OrderSend()](ordersend.md);
* [Compiler warnings](warningscompile.md) codes of warning messages that appear at compilation (not errors);
* [Compilation errors](errorscompile.md) codes of error messages at an unsuccessful attempt to compile;
* [Runtime errors](errorcodes.md) error codes in the execution of mql5-programs, which can be obtained using the [GetLastError()](getlasterror.md) function.
