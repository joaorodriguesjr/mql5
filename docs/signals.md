Trade Signals

This is the group of functions intended for managing trade signals. The functions allow:

* get information about trade signals, available for copying,
* get and set the signal copy settings,
* subscribe and unsubscribe to the signal copying using MQL5 language functions.

| Function | Action |
| --- | --- |
| [SignalBaseGetDouble](signalbasegetdouble.md) | Returns the value of double type property for selected signal |
| [SignalBaseGetInteger](signalbasegetinteger.md) | Returns the value of integer type property for selected signal |
| [SignalBaseGetString](signalbasegetstring.md) | Returns the value of string type property for selected signal |
| [SignalBaseSelect](signalbaseselect.md) | Selects a signal from signals, available in terminal for further working with it |
| [SignalBaseTotal](signalbasetotal.md) | Returns the total amount of signals, available in terminal |
| [SignalInfoGetDouble](signalinfogetdouble.md) | Returns the value of double type property of signal copy settings |
| [SignalInfoGetInteger](signalinfogetinteger.md) | Returns the value of integer type property of signal copy settings |
| [SignalInfoGetString](signalinfogetstring.md) | Returns the value of string type property of signal copy settings |
| [SignalInfoSetDouble](signalinfosetdouble.md) | Sets the value of double type property of signal copy settings |
| [SignalInfoSetInteger](signalinfosetinteger.md) | Sets the value of integer type property of signal copy settings |
| [SignalSubscribe](signalsubscribe.md) | Subscribes to the trading signal |
| [SignalUnsubscribe](signalunsubscribe.md) | Cancels subscription |
