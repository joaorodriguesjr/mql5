Environment State

Constants describing the current runtime environment of an mql5-program are divided into groups:

* [Client terminal properties](terminalstatus.md) information about the client terminal;
* [Executed MQL5-program properties](mql5_programm_info.md)  mql5 program properties, which help to control its execution;
* [Symbol properties](marketinfoconstants.md) obtaining information about a symbol;
* [Account properties](accountinformation.md)   information about the current account;

* [Testing Statistics](statistics.md) results of Expert Advisor testing.
